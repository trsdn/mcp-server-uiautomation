# UIAutomationMcp Examples

This folder contains small examples for the current UI Automation workflow.

## Included
- `mcp-configs\` - ready-to-edit MCP configuration samples for common clients

## Current command examples
```powershell
uiamcp desktop
uiamcp focused
uiamcp find-name "Calculator"
uiamcp find-class "Notepad"
uiamcp find-automation-id "SearchBox"
```

These commands inspect live desktop UI through Windows UI Automation.
